# Skips applied only when this machine cannot create symlinks - read by
# test/official_suite/CMakeLists.txt, which probes the capability instead of guessing from
# the platform name.
#
# Creating a file symlink on Windows requires SeCreateSymbolicLinkPrivilege, which a normal
# unprivileged process does not have. It is a property of the account Windows gives you
# (developers with Developer Mode enabled, most CI images: fine; a plain local shell: EPERM),
# so the port cannot fix it and the platform name cannot predict it. Hence the probe.
#
# All 28 entries below were measured as EPERM failures on such a machine with the port-built
# executable (2026-10-16). They are expected to pass wherever symlinks are permitted, and
# they are re-examined on every Node.js version bump.
#
