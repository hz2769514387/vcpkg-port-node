## 2. 剩下的 Windows 2~4 条：判为 CI 侧抖动，但**两轮都拿不到退出码**

证据：
1. **本机复现不了**：用本工程自己编的 node.exe（x64-windows）跑这 6 条，
   * 平跑 10 次/条 → **全过**；
   * 再起 8 个 CPU 满载、6 条并发跑 5 轮（30 次）→ **全过**。
2. **同用例在 Linux 上全绿**（run #31 的 x64-linux 是 5114/5114）。
3. **集合每轮都在换**：#29 是另外 3 条、#31 是这 2 条、arm64-windows 又是另外 4 条。
4. **不是 crash 也不是 timeout**：test.py 只在 `HasCrashed()`（0x80000000 高位那类）
   或超时才打印标记，日志两样都没有 ⇒ 退出码落在 1..0x7FFFFFFF 且**零输出**
   —— 而这种"静默失败"上游恰恰**不打印退出码**，所以日志里没有任何可判读的线索。

于是提交 `8110ce0`（port patch **0018**）：让 `tools/test.py` 的**所有**失败都打印
`--- exit code: N (0xXXXXXXXX) ---`（Windows 的 NTSTATUS 十六进制才看得懂）。下一轮这两档的
退出码就是判据：`0xC0000005`(访问违例)/`0xC00000FD`(栈溢出)/`0xC0000409`(fail-fast)
⇒ 是我们自己的问题（要继续挖）；`0xC000013A`(被外部结束)/普通小码 ⇒ runner 侧。

## 3. macOS 那 3 条：**不是抖动**（跨 4 轮都在）

`test-worker-track-unmanaged-fds` / `test-worker-debug` / `test-esm-import-meta-main-eval.mjs`
在 #28、#29、#30、#31 反复出现（#30 那轮因为我的临时根错误被淹掉，但名字仍在表里）。

它们的**共同线索是 worker + fd 追踪**：
* `test-worker-track-unmanaged-fds`：`Warning: File descriptor 13 opened in unmanaged mode twice`
  → `closed but not opened in unmanaged mode` → `Error: EBADF: bad file descriptor, close`；
* `test-esm-import-meta-main-eval.mjs`：一个**没开追踪**的 worker，其 stderr 里冒出
  `Warning: File descriptor 14 closed but not opened in unmanaged mode`（期望 stderr 为空）；
* `test-worker-debug`：`--- TIMEOUT ---`（等 debugger 输出超时）。

`tracks_unmanaged_fds()` 是 `EnvironmentFlags::kTrackUnmanagedFds`，而
`src/node_worker.cc:717` 会让**子 worker 继承**父环境的追踪开关 —— 值得顺着"父环境为什么开着追踪"
与"fd 13/14 是谁的"往下查。**本机没有 macOS，复现不了**，只能靠 CI（Tier 2，先记账）。

Hmm，另一条待查的：macOS 上 `test-permission-fs-*` 那批在 #30 出现过（#31 没有）—— 跟着临时根一起回的绿，暂按已解决。

## 4. 我的建议（等下一轮退出码落地再定）

对 **x64-windows 硬门被 2/5114 条 CI-only 抖动卡红**这件事，不要动"硬门"的语义。建议顺序：
1. 先让 `0018` 生效，拿到退出码与（若有）崩溃类型 —— 一轮 CI 就能定性；
2. 若定性为 runner 侧（例如被外部结束），把**已经复现过的那几条**逐条登记进
   `test/cmake/node-suite-skips.txt`，理由按清单规则写全（"CI-only + 本机 10/10 与满载 30/30 不复现
   + 同用例 Linux 全绿 + 退出码 X + 日期"），**而不是**放宽硬门或改成"允许失败"；
3. 若定性为我们自己的崩溃（0xC0000005 / 0xC00000FD / 0xC0000409），则回到"崩在原生层的先怀疑自己"，
   继续挖（那时至少要拿 clang 22 / VS 18 口径复现）。
