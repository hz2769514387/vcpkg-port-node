根因（新旧逐行对出来的，确凿）
deps/v8/src/libplatform/tracing/recorder.h(19,2):
  error: "only include this file if V8_ENABLE_SYSTEM_INSTRUMENTATION"
FAILED: v8/CMakeFiles/v8_libplatform.dir/.../src/libplatform/tracing/recorder-win.cc.obj
generated/v8_libplatform.cmake：
SOURCES_WIN 有 recorder-win.cc	DEFINES_WIN 有 V8_ENABLE_SYSTEM_INSTRUMENTATION
旧 port（git HEAD~1）	有	有
新 port（vcpkg-port-node）	有	没有（就这一行没了；win 段还少 V8_SHORT_BUILTIN_CALLS）
而这两样在 gyp 里是同一个开关的两条分支：tools/v8_gypfiles/v8.gyp:1695（v8_enable_system_instrumentation==1 and is_win 加源）与 tools/v8_gypfiles/features.gypi:524（同名条件加宏）。所以"源在、宏没了"只能是重新生成时求值不一致 —— 宏那条分支没进来，源那条照旧收了。
