## 1. debug 构建的 CI 实测 ★ 用户已决策必做

- **现状**：CI 全部 triplet 都是 `VCPKG_BUILD_TYPE release`（省盘省时，见
  `triplets/*-ci.cmake` 注释）。debug 从未被 CI 编译过。
- **风险**：V8 debug 构建体积/时长约翻倍；路线 B 的补丁（PCH、`/std:` 分语言发出、
  rsp 文本处理）在 debug 口径下未验证过。debug-only 的编译错误完全可能存在。
- **绕超时方案（用户提议）**：CI 的 6 小时超时是单次 run 的限制——
  **两次 push 配置不同**：push A 跑 release 矩阵，push B（改 workflow 触发变量或
  专用分支）只跑 debug 矩阵；或用 `workflow_dispatch` 手动触发 debug 专用 job。
- **验收标准**：debug 口径下 node 静态库链接成功 + test 侧消费通过。
- 状态：⬜ 未做
