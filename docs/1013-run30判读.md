## 2. 本轮失败几乎全部由**我上一轮那个改动**引起（两个方向同时炸）

临时根（`NODE_TEST_DIR`）同时受两个方向约束：

* **① 绝对侧**：`tmpdir.resolve()` 给绝对路径 ⇒ `<临时根>/.tmp.<id>/copy_%<n>/<pid>.sock`
  （用例：`test-fs-cp-*-socket`）
* **② 相对侧**：`common.PIPE = path.relative(process.cwd(), tmpdir.path) + '/node-test.<pid>.sock-…'`
  （`test/common/index.js:257`）cwd = 套件根 ⇒ 前面会带"上溯到公共祖先"的若干层 `../`
  （用例：`test-net-*` 一族）

我上一轮改成了"系统临时目录 + `node-suite-tmp/node-suite`"：

| 平台 | 症状 | 实测证据 |
|---|---|---|
| Linux/macOS | ② 变成 **13 层 `../`（39 字符）**，总长 129 > 107 ⇒ `listen EINVAL` | `../../../../../../../../../../../../../tmp/node-suite-tmp/node-suite/.tmp.2359/node-test.83539.sock-net-connect-options-fd-server`（129 字符） |
| Windows | ③ 新问题：CI 的 `%TEMP%` 是 **8.3 短名** `C:\Users\RUNNER~1\AppData\Local\Temp` ⇒ 路径比对类用例整片红 | `test-fs-realpath`：`RUNNER~1` vs `runneradmin`；`test-fs-watch`：`'h2\\bar' !== 'bar'`；`test-fs-promises`：`runner~1` vs `runneradmin` |

> 教训（值得记）：**"把临时目录搬到 /tmp 就短了"是错的**。相对路径的长度由
> "cwd 到目标"的层数决定，而 cwd 是套件根（深）；Windows 的路径还要提防 8.3 短名。

## 3. 修法（提交 `9b0a721` + `d65cce0`）

* 基目录取**构建目录**（与 cwd 同在一棵树里 ⇒ ② 的 `../` 只有 5 层），目录名取 `ns`，
  **单用例时连子目录都不套**（每个字符都在预算里）；分片时才用 `t0/t1/…`。
* 按这套布局算出来的实际值（写进注释，附算式）：

  | 平台 | 绝对侧（上限） | 相对侧（上限） |
  |---|---:|---:|
  | Linux CI | 98（107） | 80（107） |
  | macOS CI | 99（**103**，余量最薄） | 80（103） |
  | 本机 Windows | 87 | 80 |

* **把规则变成脚本**：新增 `_node_suite_assert_socket_budget()` —— 配置期按上面两个公式
  算 socket 路径长度，超上限直接 FATAL（附算式与处置办法）；实测极端布局 143/89 命中。
* 补一条 Windows 专项红线：基目录含 8.3 短名（`~`）就 FATAL
  —— 这条**本来就能拦住我自己的错**。
* 踩到的 CMake 坑也记进注释：`string(REGEX REPLACE "^\\.\\./" …)` 一次调用会把**所有**
  能匹配的 `../` 都吃掉（`../../../../../ns` → `ns`，层数误算成 1）⇒ 层数要用 `MATCHALL` 数。
