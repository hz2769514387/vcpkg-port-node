# Code of conduct

This project follows the [Contributor Covenant, version 2.1][cc]. Read it there rather than here:
one canonical text is better than a paraphrase that drifts.

In short, because the short version is what matters day to day:

- Assume the other person is acting in good faith and knows something you do not.
- Critique the change, not the person; "this breaks the arm64 leg, here is the run" is the shape
  of a useful comment.
- Measured facts settle arguments here. A run id beats an opinion, and so does "I was wrong, the
  log says otherwise".
- No harassment, no personal attacks, no dismissing someone for what they do not know yet.

## Reporting

Use GitHub's **private vulnerability reporting** on the *Security* tab, or email the maintainer
through the address on their GitHub profile — either reaches the same person privately. Reports are
read by the maintainer alone, and a report about behaviour is handled the same way as a report
about code: privately, and with an answer.

Enforcement follows the Contributor Covenant's [enforcement guidelines][eg]: correction, warning,
temporary ban, permanent ban — in that order, and only as far as the behaviour requires.
